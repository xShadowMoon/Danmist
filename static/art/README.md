# Your own artwork

The repo ships without images except the app icons. Drop transparent PNG/WebP files here with these names and they are picked up automatically (refresh the OBS browser source). Delete a file to go back to the default look.

| File | Used for | Suggested size |
| --- | --- | --- |
| `guard3.png` / `guard2.png` / `guard1.png` | 舰长 / 提督 / 总督 badge | 128×128 |
| `frame3-s.png` / `frame2-s.png` / `frame1-s.png` | Avatar frame for guards | 96×96, transparent centre |
| `banner3.png` / `banner2.png` / `banner1.png` | Guard purchase banner background | 900×180, keep the left two thirds calm for text |
| `xw-connect.webp` | Picture on the "reconnecting" screen | ~120×120 |
| `xw-empty.webp` | Picture on empty panels | ~92×92 |
| `xw-clap.webp` | Picture next to big gift effects | ~80×80 |
| `diary-xw.webp`, `diary-seal.webp` | Mascot and SC wax seal in the "留言本" OBS style (`xw=1` in the OBS URL shows the mascot) | ~160×160, ~48×48 |
| `mist-peek.webp` | Corner mascot in the "薄雾" OBS style (`peek=1`) | ~200×200 |
