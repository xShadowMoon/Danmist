# Your own artwork

The repo ships without images except the app icons. Bilibili's official guard frames and badges are fetched from Bilibili at runtime (they are not part of the repo). Drop transparent PNG/WebP files here with these names and they are picked up automatically (refresh the OBS browser source). Delete a file to go back to the default look.

| File | Used for | Suggested size |
| --- | --- | --- |
| `guard3.png` / `guard2.png` / `guard1.png` | 舰长 / 提督 / 总督 badge (Bilibili's official badge is used when missing) | 128×128 |
| `frame3-s.png` / `frame2-s.png` / `frame1-s.png` | Avatar frame for guards on the dashboard (Bilibili's official frame is used when missing) | 96×96, transparent centre |
| `frame3-v2.png` / `frame2-v2.png` / `frame1-v2.png` | Avatar frame for guards in the OBS overlay (official frame when missing) | 200×200, transparent centre |
| `banner3.png` / `banner2.png` / `banner1.png` | Guard purchase banner background | 900×180, keep the left two thirds calm for text |
| `xw-connect.webp` | Picture on the "reconnecting" screen | ~120×120 |
| `xw-empty.webp` | Picture on empty panels | ~92×92 |
| `xw-clap.webp` | Picture next to big gift effects | ~80×80 |
