雾幕 Danmist · 使用说明
========================

雾幕是给 B 站主播用的弹幕工具：在电脑上看弹幕、礼物、SC、上舰，朗读弹幕，做 OBS 弹幕和歌单，免费、开源。
也能同时收斗鱼、虎牙、抖音直播间的弹幕。


一、下载哪个
------------
一般下载「Danmist-Setup-版本号.exe」就行（安装版，最省事）。

另一个「…windows-x64.zip」是免安装版：解压到一个文件夹，双击里面的 start.bat 打开。
不想装到电脑上、或者想放在 U 盘里用的才选它。两个选一个就行。


二、安装和第一次打开
--------------------
1. 双击 Danmist-Setup-版本号.exe。
   如果 Windows 提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
   （安装包没有花钱买数字签名，所以会这样提示，不是病毒。）
2. 不需要管理员权限，也不用另外装 Python，一会儿就装好，开始菜单和桌面上会有「雾幕」。
3. 第一次打开会出一张卡片：选平台（B 站 / 斗鱼 / 虎牙 / 抖音），填直播间号（B 站是直播间网址最后那串数字）。
   填错了没关系：设置 → 直播间 里随时能改。
4. 点弹幕栏下面、发送框左边的头像，用 B 站 App 扫码登录。
   不登录也能用，但观众的名字会显示成打码的样子。


三、常用的地方
--------------
· OBS 弹幕：右上角「OBS 弹幕」，选好样式点「复制网址」，在 OBS 里加一个「浏览器」来源，把网址粘进去。
· 朗读弹幕：右上角「朗读」打开，设置 → 朗读 里选声音、读什么。
· 其他平台：设置 → 直播间 → 同时收其他平台的弹幕，加斗鱼、虎牙、抖音的房间号。
· 切换直播间：设置 → 直播间 → 切换直播间，加几个常去的直播间，点「看」就切过去。
  抖音填直播间网址 live.douyin.com/ 后面那串数字；不登录抖音名字会打码，点「显示窗口」在弹出来的窗口里登录抖音，弄好点「藏起来」。
· 不懂的地方：每一栏标题上的「?」有讲解，设置 → 更多 → 引导 可以再看一遍新手引导。


四、更新到新版本
----------------
有新版本时顶上会出现「下载更新」，点一下，下完点「重启生效」就好。
如果软件里下载太慢或者失败：从网盘下载新的 Danmist-Setup，直接双击装一遍就是升级，
直播间号、存档、备注、设置都会保留。


五、不用了怎么删
----------------
Windows「设置 → 应用」里找到「雾幕」卸载，卸载时会问要不要连存档一起删。


六、注意
--------
· 用 B 站账号扫码登录、发弹幕如果被 B 站限制或封禁，作者不负责，请自己注意使用频率。
· 有问题或建议：GitHub https://github.com/xShadowMoon/Danmist ，或者在 B 站评论区留言。
